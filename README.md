# Elemi-AltSchool-Sem02-Exam


A markdown editor and live preview application built with **React (Vite)**, using **Vanilla CSS with BEM**, and React Router v7 for routing. The app includes a toolbar with common markdown actions and a split layout showing the editor and the live preview.

---

## ✅ Features (So Far)

- ✅ Vite + React 19 setup
- ✅ React Router integrated (`react-router-dom@latest`)
- ✅ Project architecture with pages, routes, and components
- ✅ Dark theme styling using Vanilla CSS and BEM conventions
- ✅ App layout:
  - Header with dropdown placeholders (Preview / Import / Save As) on Hover
  - Toolbar above the editor
  - Side-by-side editor & preview layout (responsive)
- ✅ Lucide React installed for toolbar icons

---

## ✅ Tech Stack

- **React 19**
- **Vite**
- **React Router**
- **Vanilla CSS (BEM naming)**
- **Lucide React (icons)**
